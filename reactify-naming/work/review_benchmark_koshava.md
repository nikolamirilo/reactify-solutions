# Independent review, benchmark: Koshava (fresh context, 2026-09-29)

VERDICT Koshava: FAIL - KOSHAVA is one letter from KOCHAVA and sounds almost the same. KOCHAVA is a live USPTO class 42 SaaS registration (Reg. 5255177) held by Kochava Inc., an established US adtech/analytics software company of about 185 people. A Serbian software/SaaS company selling to US clients would sit in the same class 42 space, so this is a confusingly similar live mark and an established similar tech name under 2.9.

Method: live sources only (Vercel domain tools, RDAP via WebFetch, TMview via Firecrawl, Firecrawl web search, GitHub MCP search). I did not read any other file under `work/`.

## Language and radio test

- Serbian: Košava (Кошава) is the cold, very squally southeast wind of Belgrade and the Danube (https://en.wikipedia.org/wiki/Ko%C5%A1ava_(wind)). It is not vulgar. Judgment: slightly harsh or unpleasant ("cold") but locally iconic.
  - In Serbia the name is also tied to TV/Radio Košava, the 1990s station owned by Marija Milošević, daughter of Slobodan Milošević (https://vivstars.com/marijina-kosava-diktatorski-mtv/, https://rtvforum.net/tv-ko-ava-1998-2010-t757.html, https://en.wikipedia.org/wiki/Ko%C5%A1ava).
  - This is a political association for local audiences, not a negative meaning of the word. Judgment: residual risk, not a disqualifier on its own.
- English, German, Spanish, French, Italian, Hungarian: I found no vulgar or negative word or homophone. Other names for the same wind (Koschawa in German, Kossava in Italian) are neutral. This is my own linguistic judgment; I did not find a dictionary source for each language.
  - The English near-homophone that matters is the brand **Kochava**. In Hebrew, kochava means "star" (https://www.kveller.com/jewish-baby-name/kochava/), which is harmless but outside the listed languages.
- Radio test: weak. Judgment.
  - Serbian stress is on the first syllable ([kɔ̌ʃaʋa] per Wikipedia), while English speakers will tend to say ko-SHAH-va, so there are two ways to say it.
  - Serbian listeners will write Košava or Kosava, not Koshava.
  - English listeners who know adtech may write Kochava.
  - "Koshava" is the most likely English spelling, but it is not the only one, and one wrong spelling leads to a competitor's brand.

## Main residual risk

The decisive problem is the KOCHAVA mark and company:
- Live USPTO Reg. 5255177 in class 42 for SaaS analytics and tracking software.
- An established ~185-person US software company with more registered marks in classes 35 and 42.
- One letter away from Koshava and nearly the same sound.
- Its name is linked to a high-profile FTC privacy case.

Planned uses such as "Koshava Labs" or product lines under "by Koshava", offered to US clients in class 42, would invite opposition or a USPTO 2(d) likelihood-of-confusion refusal. Search results already mix the two names up.

Whether USPTO would actually refuse is a legal judgment I cannot settle here. A one-letter difference plus a near-identical sound plus related class 42 software services is the standard pattern for a 2(d) refusal, so I treat it as a concrete disqualifier under 2.9 and not a soft risk.

Everything else was secondary: no live KOSHAVA marks in TMview (RS included), koshava.co available at USD 29.99/24.80, and the Serbian TV Košava association, handle scarcity and radio-test weakness.
