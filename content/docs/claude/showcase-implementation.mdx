- Phase 5 of 8, invoked once [Planning](/docs/claude/showcase-planning) and its two sub-skills are done and the user has confirmed the plan.
- The first phase in this whole tree that writes application code rather than a planning document.
- Reads every file under `docs/product/`, not just the immediately preceding one, since implementation has to honor the original idea and scope, not only the architecture.
- Deliberately conservative about deviating from the approved architecture without saying so.
