<InOneMinute>

- Phase 8 of 8, the last skill in this tree, invoked alongside [SEO](/docs/claude/showcase-seo) once [Validation and testing](/docs/claude/showcase-validation-testing) passes.
- Unlike every other phase in this example, it does not name a specific file to read. It audits the running product directly against a named external standard, WCAG 2.2 AA.
- Draws a firm line between fixes it can make on its own, contrast, labeling, and ones that need a human call, a layout change, and refuses to blur that line.

</InOneMinute>
